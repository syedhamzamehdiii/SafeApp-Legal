# SafeApp Legal Pages

Static Terms of Service and Privacy Policy for SafeApp.

## Contents

- `index.html` — Single-page site with both legal documents
- `styles.css` — Styling and layout

## Local preview

Open `index.html` in a browser, or run a simple server:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Deploy

This is plain HTML/CSS — host anywhere:

- **GitHub Pages**: Settings → Pages → Deploy from `main` branch, root `/`
- **Netlify / Vercel**: Drag the folder or connect this repo
- **Any static host**: Upload `index.html` and `styles.css`
